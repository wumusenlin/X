# 需求

## 目标

让各子项目的已提交修改自动同步到工作区最近修改快照，避免协作上下文滞后。

## 范围

- 范围内：X 根协作规则、最近修改快照、小控最新提交登记。
- 范围外：子项目业务代码、Git Hook、定时任务、自动推送 X 根仓库。

## 业务规则

- 每次代理完成子项目提交或推送后，必须刷新对应快照并在 X 根独立提交。
- 快照只记录已提交的 Git 状态，不记录未提交工作区改动。

## 项目影响

| 项目 | 是否受影响 | 范围 | 主责 |
| --- | --- | --- | --- |
| 后端 | 否 | 无 | 后端 |
| Web 端 | 否 | 无 | 前端 |
| 移动端 | 否 | 无 | 前端 |
| 小控 | 是 | 仅登记已推送提交 | 产品/小控 |
| 绩效平台 | 否 | 无 | 绩效平台 |
